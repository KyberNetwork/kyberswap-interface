Samsung Internet dark-mode probe pages

Temporary test pages. Every page paints the same colours; only the head declarations differ.

How to test: keep the phone's Dark mode ON, open each link below in Samsung Internet, wait for the grey box at the bottom to fill in, then take a full screenshot of each page. Open v0 in Chrome too, for comparison. The page whose colours match the labels in the swatches is the declaration Samsung Internet respects.

  1. v0: Control, no declaration
    No color-scheme meta, no CSS color-scheme, no media query. Expected: Samsung re-colours this page.
  2. v1: meta color-scheme dark + :root color-scheme dark
    What PR #3408 ships.
  3. v2: legacy supported-color-schemes dark
    The pre-2020 name of the same meta/property, plus color-scheme dark.
  4. v3: prefers-color-scheme media query only
    Every colour rule is repeated inside @media (prefers-color-scheme: dark). No meta, no color-scheme property.
  5. v4: meta light dark + media query
    Declares both schemes and styles the dark one through the media query, like a real light/dark site.
  6. v5: meta color-scheme only light (Chromium auto-dark opt-out)
    Tells the browser never to darken this page.
  7. v6: v1 + forced-color-adjust none + dark theme-color
    color-scheme dark plus forced-color-adjust: none on the root and a dark theme-color.
